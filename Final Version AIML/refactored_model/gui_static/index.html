Held-out targets: the default is the five named targets of the shipped held-out model (the three study targets plus T52522 and T45993); the training script adds 12 more by a seeded random draw, so the same five names give the same 17 held-out targets.

Training time depends on the GPU: about 13 minutes for 6,000 steps on the study machine (measured 5 Nov 2026), so allow longer on a slower GPU or on the CPU. The new model is saved as checkpoint_exemplar_<name>.pt; an existing file is never overwritten (the stage is skipped). To use a rebuilt base model, make it with pretrain_base_model.py (it is saved as checkpoint_pretrained_rebuild.pt and then appears in the list above).
